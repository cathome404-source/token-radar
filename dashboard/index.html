Every protocol in the 2026-11-14 DefiLlama index is scored the same way: a value curve fitted on the 128 protocols whose token already trades turns TVL into an expected market cap, and launch odds fitted on all 758 protocols turn age and size into the chance a protocol launches a token at all. Implied value is launch odds times expected market cap, and the farm verdict prices that value per hour of work. Implied value = launch odds × expected market cap from the comps curve. The comps curve’s median error is ×3.40, so every value is shown as a range (value ÷3.40 to ×3.40), not a false point estimate.

Method

implied value = P(launch) × exp(6.9646 + 0.5223 · ln(TVL))

The value curve is an ordinary least-squares fit of log market cap on log TVL over the 128 comps. P(launch) is a logistic fit on all 758 protocols: has-token ~ age in years + log(TVL), with coefficients b0 = −1.5211, b1 = +0.4506, b2 = +0.0502. The page recomputes each row’s expected market cap from its TVL with the fitted constants, so the arithmetic on this page and in the board file is the same arithmetic.

Terms tested and dropped

    Farm assumptions

    • 10% of launch value goes to farmers.
    • One farmer per $10,000 of TVL.
    • Verdict farm at ≥ $25/hour, thin at ≥ $5/hour, otherwise skip.
    • Capital by TVL band: $250 / $150 / $100 / $50. Gas per transaction: Ethereum $8, Solana $0.05, L2s and most other chains $0.50, anything else $2.

    Caveats

    Launch odds rise with age in this one cross-section because older cohorts launched more; that is the peers’ record, not a promise. A protocol records no token — never that it has none. Live rows with a recorded market cap show the market’s own number; live rows without one show the comps curve’s estimate, tagged modelled.
